# 核心流程

## 应用内 OCR 流程

1. 用户在 PackageHub 内选择图片或拍照。
2. Flutter 请求原生 OCR 能力。
3. iOS 使用 Apple Vision，Android 使用 ML Kit。
4. Flutter 对识别文本进行字段解析。
5. 用户确认后生成包裹记录。

## 包裹管理流程

1. 首页展示本地包裹列表。
2. 用户可按状态、承运商、关键词筛选。
3. 用户进入详情页查看识别文本、物流单号和事件记录。
4. 用户可手动编辑识别错误字段。

## OCR 结果解析

OCR 只负责提取文本，业务字段解析放在 Flutter 层统一处理，减少平台差异。

解析目标：

- 快递单号 / 运单号
- 承运商
- 包裹名称
- 物流状态
- 时间、地点和事件描述

解析策略：

- 使用正则匹配常见单号格式。
- 维护承运商关键词字典。
- 保留 OCR 原始文本，便于用户修正和后续算法优化。
- 将解析结果作为建议值展示，最终以用户确认结果为准。

## 身份码直达

- 身份码直达采用第三方 App Deep Link / H5 Router 实现

## 本地优先与隐私

- OCR 优先在本地设备执行。
- 包裹数据默认仅保存在本地。
- 图片路径仅保存本地引用，不上传远端服务。
